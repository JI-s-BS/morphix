# Contributing to Morphix

Open an issue to report a bug or discuss a larger change. Include your OS, Node version, reproduction steps, and relevant logs with credentials and personal information removed.

For a pull request:

1. Create a branch for your change.
2. Install dependencies with `npm ci`.
3. Make a focused change and update the relevant documentation.
4. Run `npm test`, `npm run typecheck`, and `npm run build`.
5. Describe the result and any hardware validation or checks you could not run.

Never commit API keys, environment files containing credentials, local databases, or generated build artifacts. Document printer model and firmware details when changing printer behavior. Keep physical print approval and hardware validation gates intact.

By contributing, you agree that your contributions are provided under this project's MIT license.
